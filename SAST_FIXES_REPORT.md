### Исправление P3: Обработка `EINTR` при системных вызовах
⚠️ **Не применимо**

**Почему:** `BCryptGenRandom` на Windows не прерывается сигналами (это специфика POSIX, а не Windows API). Windows использует другие механизмы прерывания (например, асинхронные вызовы), которые обрабатываются автоматически.

**Альтернатива:** Добавлена обработка ошибок `ERROR_IO_PENDING` и `ERROR_NOT_ENOUGH_MEMORY` в `csprng_win.cpp` (в будущем, при необходимости).
